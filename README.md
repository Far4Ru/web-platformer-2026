# Звёздная почта

Небольшой браузерный платформер на HTML, CSS и обычном JavaScript. Игровая графика рисуется через Canvas; внешних картинок, звука, движка, npm и сборки нет.

## Запуск

Запустите локальный HTTP-сервер в папке проекта, затем откройте его адрес в браузере. Например, при установленном Python:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Локальный сервер нужен для загрузки ES-модулей.

## Управление и цель

- Стрелки влево/вправо или A/D — движение.
- Space, W или стрелка вверх — прыжок. Повторный прыжок в воздухе невозможен.
- P или кнопка «Пауза» — остановка и продолжение.
- На телефоне используйте экранные кнопки.

Соберите три письма и доберитесь до маяка справа вверху. Шипы и падение за нижний край завершают попытку. Кнопка «Заново» начинает уровень с чистого состояния. Рекорд количества собранных писем хранится в `localStorage`, если браузер разрешает запись.

## Структура

- `index.html` — разметка, Canvas и кнопки.
- `style.css` — оформление и адаптивная компоновка.
- `main.js` — точка входа.
- `Game.js` — состояние, уровень, игровой цикл и отрисовка.
- `Player.js` — движение персонажа.
- `input.js` — клавиатура и сенсорные кнопки.
- `collision.js` — проверка и разрешение столкновений.

Игра подготовлена с помощью OpenAI Codex. Примеры запросов: «Создай платформер на Canvas без npm», «Добавь движение, прыжок и столкновения», «Добавь собираемые предметы, паузу и рекорд».
