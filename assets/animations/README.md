# Анимации

Каждая анимация находится в собственной папке объекта и состоит из двух файлов: `имя.png` со всеми её кадрами и `имя.json` с координатами кадров. Например, `explorer/run.png` и `explorer/run.json` содержат два кадра бега. Одиночные состояния тоже имеют ту же пару файлов.

В `assets/json/game.json` для каждого объекта указаны папка `base`, список `clips` и порядок кадров `order`, который использует игра. Исходные листы сохранены в `assets/spritesheets/source/`. Скрипт `scripts/build-animations.ps1` пересоздаёт пары PNG + JSON после изменения источника.
